# 会社 福利厚生・社内制度ハンドブック

## 1. 資格取得支援制度（スキルアップ支援）
社員の自己啓発を支援するため、指定資格の合格時に受験料の精算および報奨金を支給する。

### 1.1 対象資格および報奨金額一覧
| 資格区分 | 資格名 | 報奨金額 | 備考 |
| :--- | :--- | :--- | :--- |
| IT基礎 | ITパスポート | 10,000円 | 受験料補助は1回のみ |
| IT専門 | 基本情報技術者 | 30,000円 | |
| IT高度 | 応用情報技術者 | 100,000円 | |
| クラウド | AWS認定（各種） | 50,000円 | Associate以上が対象 |
| 語学 | TOEIC 700点以上 | 30,000円 | 取得から2年以内のスコア |
| 語学 | TOEIC 850点以上 | 80,000円 | 取得から2年以内のスコア |
| 語学 | 中国語検定2級以上 | 50,000円 | |
| その他 | メンタルヘルス・マネジメント検定 | 20,000円 | 2種以上が対象 |

### 1.2 申請条件と制限
- **受験料補助**: 合格時のみ実費を全額支給（領収書必須）。不合格の場合は自己負担とする。
- **回数制限**: 同一資格の受験料補助は最大2回までとする。
- **申請期限**: 合格証書の発行日から3ヶ月以内に申請すること。

## 2. 特別休暇制度
有給休暇とは別に、特定の事由において以下の通り特別休暇（有給）を付与する。

### 2.1 慶弔休暇
- **本人の結婚**: 5連続日（入籍または挙式のいずれか早い方から1年以内）
- **子、兄弟姉妹の結婚**: 1日
- **配偶者の出産**: 3日（出産予定日または出産日から1ヶ月以内）
- **忌引（配偶者、子、父母）**: 5日
- **忌引（祖父母、兄弟姉妹）**: 3日

### 2.2 リフレッシュ休暇
- 勤続5年ごとに、連続5日間の特別休暇を付与する。
- 勤続10年、20年、30年の節目には、休暇に加え「リフレッシュ支援金」を支給する。詳細は第12章を参照。

### 2.3 ボランティア休暇
- 認定された社会貢献活動に参加する場合、年間最大3日間まで取得可能。

## 3. 住居・通勤手当
### 3.1 家賃補助（住宅手当）
- **対象**: 世帯主であり、賃貸物件に居住する30歳未満の社員。
- **支給額**: 
    - 勤務地から2km圏内：月額 30,000円
    - 上記以外：月額 15,000円
- **条件**: 通勤交通費の支給額が月額5,000円以下であること。

### 3.2 通勤交通費
- **上限**: 月額 50,000円まで実費支給。
- **制限**: 特急料金、グリーン車料金は原則として自己負担。新幹線通勤は片道100km以上かつ上長承認がある場合のみ認める。

## 4. 健康・ウェルビーイング
### 4.1 スポーツジム補助
- 提携スポーツクラブ、または任意のフィットネスジムの月会費を、月額最大3,000円まで補助する。
- **条件**: 月4回以上の利用記録（レシートまたはアプリ画面等）の提出が必要。

### 4.2 人間ドックオプション補助
- 35歳以上の社員が定期健康診断を人間ドックに切り替える際、オプション費用を最大20,000円まで会社が負担する。

## 5. 働き方・環境支援
### 5.1 在宅勤務（リモートワーク）手当
- **支給対象**: 月の所定労働日数の50%以上を在宅で勤務した社員。
- **支給額**: 月額 5,000円（通信費・光熱費等の実費補填）。
- **PC周辺機器補助**: 入社時または在宅勤務開始時に、ディスプレイ、椅子等の購入費用を最大30,000円まで補助（1回限り）。

### 5.2 自己研鑽図書費
- 業務に関連する書籍の購入費用を、月額 2,000円まで全額補助する。
- 電子書籍も対象とするが、領収書の発行が必要。

## 6. 食事・カフェテリア支援
### 6.1 ランチ補助
- 提携の食事予約サービス、または社内設置の自動販売機・オフィスコンビニにて利用可能なポイントを、毎月2,000ポイント付与する。
- 余ったポイントは翌月末まで繰り越し可能。

### 6.2 懇親会費用補助
- 部署内でのコミュニケーション活性化を目的とした会食について、1人あたり4,000円を上限に四半期に1回まで補助する。

## 7. 育児・介護支援制度
### 7.1 ベビーシッター利用補助
- 延長保育や病児保育に伴いベビーシッターを利用する場合、利用料金の半額（月額最大20,000円まで）を補助する。

### 7.2 介護用品購入補助
- 家族の介護を必要とする社員に対し、介護用品（おむつ、車椅子レンタル等）の費用を月額 5,000円まで補助する。

## 8. 財産形成・貯蓄支援
### 8.1 従業員持株会
- 自社株を購入する場合、拠出金額に対し10%の奨励金を会社から付与する。

### 8.2 企業型確定拠出年金（401k）
- マッチング拠出制度を導入。社員の拠出額と同額（最大 5,000円まで）を会社が上乗せして拠出する。

## 9. 慶弔見舞金制度
特別休暇とは別に、以下の通り祝金・見舞金を支給する。
- **結婚祝金**: 30,000円
- **出産祝金**: 20,000円（第1子より）
- **弔慰金（配偶者、子、父母）**: 50,000円
- **傷病見舞金（1ヶ月以上の入院時）**: 20,000円

## 10. クラブ活動・レクリエーション支援
- 5名以上の社員で構成される公認クラブに対し、活動費を補助する。
- **補助額**: 部員1名につき月額 1,000円（上限月額 20,000円/団体）。
- **対象例**: 野球、フットサル、ボードゲーム、プログラミング研究など。

## 11. 教育・研修自己研鑽支援
### 11.1 社外セミナー受講費
- 業務に直接関連する外部セミナーや有料講習の受講料を、年間最大 50,000円まで補助する。
- 事前に上長の承認および受講後の報告書提出が必須。

### 11.2 オンライン学習プラットフォーム
- 会社指定のオンライン学習サービス（Udemy, Coursera等）を無料で利用可能。

## 12. 永年勤続表彰制度
長期間にわたり会社に貢献した社員に対し、感謝の意を表して以下の通り授与する。
- **勤続10年**: 表彰状、特別休暇3日、リフレッシュ支援金 30,000円
- **勤続20年**: 表彰状、特別休暇5日、リフレッシュ支援金 100,000円
- **勤続30年**: 表彰状、特別休暇10日、リフレッシュ支援金 200,000円

## 13. その他・生活支援サービス
### 13.1 提携宿泊施設・レジャー
- 契約している福利厚生アウトソーシングサービス（ベネフィット・ワン等）を通じて、全国の宿泊施設や映画館、遊園地を優待価格で利用可能。

### 13.2 顧問弁護士・税理士相談
- 私生活上の法的トラブルや確定申告に関する相談について、初回30分に限り無料で提携専門家に相談可能。
