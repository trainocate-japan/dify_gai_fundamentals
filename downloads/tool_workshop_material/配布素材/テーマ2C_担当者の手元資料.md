## 2. 作成中の文書（3種類）

1件の購買依頼について、宛先の違う文書をそれぞれ手作業で用意しています。
いずれも書きかけの下書きで、内容が一覧やルールと合っているかの確認は、まだ済んでいません。

### 2-1. 依頼部門へ送る手続き案内メールの下書き（調達課が作成）

```
件名：【ご案内】購買依頼の手続きについて

各位
調達課です。購買依頼の流れをご案内します。

・50万円以上の購買は、依頼部門の課長決裁で進められます。
・相見積は、300万円以上の場合のみ2社から取得してください。
・新規の取引先の場合、発注書の発行と並行して取引先登録を進めます。
・検収は、納品書がなくても納品物を確認できれば登録可能です。

ご不明な点は調達課までご連絡ください。
```

### 2-2. 取引先へ送る発注連絡文の下書き（調達課が作成）

```
件名：発注のご連絡

株式会社〇〇 御中

先日お見積りいただいた件、発注させていただきます。
よろしくお願いいたします。
```

## 3. 前回送った文書（形式の参考）

同じ種類の文書で、前回そのまま送れたものです。書き方や項目の並べ方の参考にしてください。
（前回：情報システム部からのサーバー保守契約／税抜120万円／既存取引先）

### 3-1. 依頼部門へ送った手続き案内

```
件名：【調達課】購買依頼の手続きについて（サーバー保守契約）

情報システム部 中村様

お世話になっております。調達課です。
購買依頼を受け付けました。今回の手続きを下記のとおりご案内します。

【今回の金額区分】税抜120万円（50万円以上300万円未満）

【手続きの流れ】
1. 契約：購買依頼の起票（依頼部門の部長決裁）、相見積2社以上の取得、契約書の作成依頼と押印申請
2. 発注：決裁完了後、調達課が発注書を発行します
3. 検収：納品後、依頼部門で納品物を確認し、納品書を添えて検収を登録してください
4. 支払い：検収の登録完了後、請求書と検収書をもとに支払依頼を登録します

【ご用意いただくもの】
・見積書2通以上
・契約内容確認シート（契約書の作成依頼に必要です）
・納品書（検収時に必要です）

【想定される所要日数】
契約書の法務レビューに7営業日、押印申請に3営業日、発注書の発行に2営業日を見込んでください。

【ご注意】
発注書の発行前に、取引先へ作業を依頼することはできません（発注前着手の禁止）。

ご不明な点は調達課（chotatu@example.local）までご連絡ください。
```

```
株式会社〇〇システムサービス

・品目：サーバー保守サービス（1年間）

【発注書の送付】
発注書は本メールに添付しております。ご確認をお願いいたします。

【納品と検収について】
作業完了後、納品書のご送付をお願いいたします。
納品書を確認のうえ、当社にて検収を登録いたします。
お支払いは、請求書を受領した月の翌月末となります。

よろしくお願いいたします。
```
